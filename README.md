# SHADID AHAMED — Architecture Portfolio

Premium personal architecture portfolio website.

## How to use
1. Clone / download this repository.
2. Replace every image in `assets/` with your own (keep filenames or update paths in HTML).
3. Edit contact `href` values in `index.html`.
4. Add your real YouTube video IDs and CV PDF.
5. Open `index.html` locally or push to GitHub Pages / Netlify / Vercel.

## Favicon
Place your favicon as `assets/favicon.png`.

## 3D Hero Video
Optional: put a slow-motion 360° rotating architectural model video as `assets/hero-3d.mp4`.

## No invented data
All grades, certificates, social links, project details are placeholders ready for your real content.
